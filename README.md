# FormLab — Assignment #4

A colorful and responsive website demonstrating HTML forms, HTML5 validation, and Bootstrap form styling.

THE PAGE -----> https://pups1ch1kbbg-wq.github.io/Web-Assik4/

## About the Project

This project was created as part of Frontend Development Assignment #4. It demonstrates how to build user-friendly forms with HTML, CSS, JavaScript, and Bootstrap 5.

## Features

- Simple Contact Form
- HTML5 Form Validation
- Bootstrap Form Styling
- Bootstrap Validation Feedback
- Registration Form
- Responsive Layout
- Navigation between all tasks
- Custom colorful design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Use the navigation bar to explore the tasks.

You can also run the project using the Live Server extension in Visual Studio Code.

## Deployment

The website can be deployed using GitHub Pages or Netlify.
